# TASK: IMPLEMENT COMPLETE YOAST-STYLE SEO SYSTEM IN MY EXISTING WEBSITE

Act as a Senior Technical SEO Engineer, SEO Architect, and Full-Stack Developer.

Your task is to audit, implement, and optimize my EXISTING WEBSITE with a complete Yoast SEO-style system, following modern technical SEO, on-page SEO, content SEO, structured data, and AI search optimization practices.

## 1. FIRST: INSPECT THE EXISTING WEBSITE

Before changing anything:

1. Identify the framework, programming language, CMS, database, and hosting architecture.
2. Inspect the existing routing system and all public-facing pages.
3. Inspect existing SEO metadata, robots.txt, sitemap, canonical tags, and schema.
4. Identify duplicate URLs, indexing problems, broken links, and performance issues.
5. Identify existing SEO functionality to avoid duplication.
6. Create a list of issues and an implementation plan.

IMPORTANT:
- Do not rebuild the website.
- Do not change the existing design unnecessarily.
- Do not remove existing functionality.
- Do not break existing URLs.
- Preserve existing database records.
- Take appropriate backups before modifying critical files or database structures.

- SEO title

- Robots index/noindex
