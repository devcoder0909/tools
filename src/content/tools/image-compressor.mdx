## How to Choose the Right Image Quality

Image quality and file size are closely connected. Higher quality usually preserves more visual detail but creates a larger file. Lower quality can reduce the file size further, but may introduce blur, blockiness, color banding, or other compression artifacts.

Use these general guidelines when adjusting quality:

- **High quality:** Suitable when visual detail matters and the file-size limit allows a larger image.
- **Medium quality:** A practical starting point for many everyday photos and online uploads.
- **Lower quality:** Useful when a strict file-size limit is more important than fine detail, but inspect the result carefully.
- **Very small target sizes:** May require reducing image dimensions as well as adjusting quality. A complex photograph may not fit an extremely small limit without noticeable quality loss.

A quality percentage is an encoder setting, not a universal measure of how good an image will look. Different image formats and browsers can produce different results at the same percentage.

## Image Compression vs. Image Resizing: What's the Difference?

Image compression and image resizing can both reduce file size, but they do different things.

- **Image compression** changes how image data is encoded. Lossy compression can reduce file size by discarding some visual information; lossless compression reduces storage requirements without intentionally discarding image data.
- **Image resizing** changes the pixel dimensions, such as reducing an image from 4000 × 3000 pixels to 1600 × 1200 pixels. Fewer pixels generally require less storage.
- **Image format conversion** changes the output format, for example from PNG to JPEG or WebP. The resulting file size and visual quality depend on the source, output format, and encoder settings.

If you need to meet a strict KB limit, compression alone may not be enough. Reducing the dimensions can help, but make sure the final image still meets the portal's minimum dimensions and clarity requirements.
