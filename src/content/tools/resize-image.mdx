## Resize Images by Pixels or Percentage

Different tasks require different resizing methods. ZixTool makes it possible to adjust image dimensions according to your requirements.

### Resize by Exact Pixel Dimensions

Pixel-based resizing is useful when a website, application, form, or design template specifies an exact image width and height.

For example:

- Resize a profile photo to 400 × 400 pixels.
- Prepare a website thumbnail at 600 × 400 pixels.
- Create a square product image at 800 × 800 pixels.
- Reduce a large photograph to 1200 pixels wide.

Enter the required dimensions in the width and height fields. When the aspect ratio lock is enabled, changing one dimension automatically adjusts the other proportionally.

### Resize by Percentage

Percentage-based resizing is useful when you want to make an image larger or smaller relative to its original dimensions.

For example:

| Resize Percentage | Result |
| :--- | :--- |
| 25% | One-quarter of the original width and height |
| 50% | Half of the original width and height |
| 75% | Three-quarters of the original dimensions |
| 100% | Original dimensions |
| 150% | One-and-a-half times the original dimensions |
| 200% | Double the original width and height |

Increasing image dimensions does not guarantee improved visual quality. Enlarging a small image can make it appear softer or pixelated because the browser must interpolate additional pixels.

### Understanding Aspect Ratio

An image's aspect ratio describes the relationship between its width and height.

For example, an image measuring 1200 × 800 pixels has a 3:2 aspect ratio.

If you resize its width to 600 pixels while preserving the original ratio, the resulting height is 400 pixels.

This prevents unwanted stretching and keeps the original proportions.

If you enter unrelated width and height values with the aspect ratio lock disabled, the image may appear stretched or compressed.

## Image Resizing vs Image Compression

Image resizing and image compression solve different problems.

| Comparison | Image Resizing | Image Compression |
| :--- | :--- | :--- |
| **Main Purpose** | Change width and height | Reduce file size |
| **Primary Setting** | Pixels or percentage | KB, MB, or quality |
| **Changes Dimensions** | Yes | Not necessarily |
| **Can Reduce File Size** | Often, but not guaranteed | Yes |
| **Useful For** | Website dimensions and form requirements | Upload limits and storage |

If an application requires a photograph to be 200 × 230 pixels and below 50KB, you may need both operations: resize the image to the required dimensions and then compress it to meet the file-size limit.

## Troubleshooting Common Image Resizing Problems

### The Resized Image Looks Blurry

Blurriness can occur when a small image is enlarged significantly. Upscaling cannot recreate details that were not present in the original image.

**What to do:** Start with the highest-quality original image available. Avoid enlarging a very small photograph more than necessary.

### The Image Looks Stretched

This usually happens when the width and height are changed independently without preserving the original aspect ratio.

**What to do:** Enable the aspect ratio lock and change only one dimension. The other dimension should adjust proportionally.

### The Downloaded File Is Still Too Large

Changing image dimensions does not guarantee a particular file size. A detailed photograph may remain relatively large even after resizing.

**What to do:** Use the [ZixTool Image Compressor](/image-compressor/) to reduce the output file size.

### The Image Does Not Upload or Display

Some files may fail to load because they are corrupted, unsupported, or too large for the available browser memory.

**What to do:**
- Try opening the original image on your device.
- Use a supported JPG, PNG, or WebP file.
- Try a smaller image if your device has limited memory.
- Refresh the page and select the image again.
- Use an updated browser.

### The Image Dimensions Do Not Match a Form Requirement

Check whether the portal specifies width and height in pixels, a maximum file size, or a particular aspect ratio.

**What to do:** Enter the exact required pixel dimensions and verify the exported image before uploading it to the application portal.
