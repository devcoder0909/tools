Compress PDF online by rewriting the document with object streams in your browser. This can reduce structural overhead in some files, but it does not guarantee a smaller result or a particular KB limit. Compare the saved file with your original before using it.

## Reduce PDF file size for email or an upload form

Read the recipient's file limit and compare it with the size of the actual download. If the total is still too large and the recipient accepts separate attachments, [split the PDF](/split-pdf/) into meaningful sections. For a scanned document where every page is a full-page picture, start with the original images or the scanner's export settings. The [PDF file size guide](/guides/pdf-file-size-limits/) explains when each approach is likely to help.

## How to try PDF compression

1. Select your PDF using the file picker above. Keep a copy of the original document.
2. Run the compression operation and wait for the result. Large documents may require more time and available browser memory.
3. Download the result, check its actual size, and open it in a PDF viewer. Keep the smaller valid copy after comparing page count, legibility, and document features.

## What this PDF compressor actually changes

The current tool uses the JavaScript pdf-lib library to load and save a PDF with object streams enabled. Object streams can store PDF objects more compactly. This is a structural rewrite, not a scan optimizer or a general document repair service.

It does not currently resample embedded images to a chosen DPI, remove unused font glyphs, perform OCR, or search for an exact output byte count. Choosing a compression label in an interface does not establish that these operations are implemented. The result depends on how your original PDF was created and whether its internal structure can be stored more compactly.

The [pdf-lib save options](https://pdf-lib.js.org/docs/api/interfaces/saveoptions) describe the underlying object-stream setting. For a practical explanation of different size-reduction methods, see our [PDF file size limits guide](/guides/pdf-file-size-limits/).

## Can I compress a PDF to 200KB, 500KB or 1MB?

You can compare the output with one of these limits, but this tool cannot promise to reach it. A scanned document that stores each page as an image may stay close to its original size because this operation does not recompress those images. An already optimized document may show little reduction or become larger after rewriting.

If you have the source document, export a new PDF with image settings suitable for the recipient. If your source is a group of photographs, prepare readable, smaller image copies with the [image compressor](/image-compressor/) before using [JPG to PDF](/jpg-to-pdf/). Check the complete PDF size afterward: several small source images still add up.

When the recipient permits selected pages only, [Split PDF](/split-pdf/) can create a smaller subset. Do not remove required pages just to pass an upload limit. For combined attachments, check the recipient's total allowance before using [Merge PDF](/merge-pdf/).

## Why the output may not be smaller

PDF files can contain text objects, images, fonts, form fields, annotations, and other data. Different optimizers act on different parts of that structure. Rewriting object streams cannot guarantee substantial savings when most of the bytes belong to images that remain unchanged.

Keep both files temporarily and compare their exact byte counts rather than rounded MB labels. A small reduction is useful only if the new document still meets your needs. There is no reason to replace a valid original with a larger output solely because the output was produced by a compressor.

## Check quality and document features

Open the saved document and inspect the first and last pages, small text, diagrams, and any signatures. Confirm the page count and orientation. Use [Rotate PDF](/rotate-pdf/) if an allowed orientation change is needed, then verify the new copy again.

Keep electronically signed originals. Rewriting can affect signature validation or document features even if the visible pages look the same. Do not assume the output is suitable for archival, legal, or regulated workflows solely because it opens in a viewer.

## Processing and privacy

This compression operation runs in your browser. The selected PDF is loaded into browser memory; it is not uploaded by the compression function. The website and its resources still need to load, so this statement does not mean visiting the website creates no network activity.

Available memory varies by device, browser, and the size and complexity of your PDF. If processing fails, try a smaller permitted document or a device with more available memory. The current implementation does not establish HIPAA, GDPR, PDF/A, or other compliance certification.

## Before submitting the file

Read whether the upload limit applies to one file or to the entire submission. Confirm that the page accepts PDF and select the latest downloaded copy. If the file is under the size limit but still rejected, investigate the actual error instead of repeatedly recompressing it.
