## The Computer Science of 200KB Compression: DCT & Quantization Math

Compressing a high-resolution 5MB image down to 200KB requires an **optimal balance between spatial frequency removal and typographic preservation**:

### 1. RGB to YCbCr Matrix Conversion & Chrominance Subsampling
Natural images are captured in RGB space. ZixTool converts RGB coordinates into the **YCbCr color space**:
- **$Y$ (Luminance):** Grayscale brightness, capturing sharp geometric edges and fine facial lines.
- **$Cb$ and $Cr$ (Chroma):** Blue-difference and red-difference color nuances.

By applying **4:2:0 chrominance subsampling**, the horizontal and vertical resolution of color channels is halved. This discards 50% of the raw color matrix before quantization begins, with zero perceptible loss in photographic sharpness.

### 2. The $8 \times 8$ Discrete Cosine Transform (DCT)
The image is divided into regular blocks of $8 \times 8$ pixels. The forward Discrete Cosine Transform maps spatial pixel intensities into 64 frequency coefficients:

$$F(u,v) = \frac{1}{4} C(u) C(v) \sum_{x=0}^{7} \sum_{y=0}^{7} f(x,y) \cos\left[\frac{(2x+1)u\pi}{16}\right] \cos\left[\frac{(2y+1)v\pi}{16}\right]$$

### 3. Binary Search Re-Quantization Loop
ZixTool tests candidate quantization values iteratively in browser RAM to find the exact highest optical quality score where:

## Binary (204,800 Bytes) vs Decimal (200,000 Bytes) Ceilings

A major reason candidate uploads fail on government portals is the subtle difference between binary and decimal byte accounting:
- **Binary Kilobyte (KiB):** $200\text{ KiB} = 200 \times 1,024 = \mathbf{204,800\text{ bytes}}$. Windows File Explorer and Linux report file sizes using this binary standard.
- **Decimal Kilobyte (KB):** $200\text{ KB} = 200 \times 1,000 = \mathbf{200,000\text{ bytes}}$. Some strict web validators use decimal division ($200,000$ bytes).

ZixTool calibrates its 200KB ceiling conservatively to ensure your compressed file remains strictly beneath **$195,000\text{ to } 198,000\text{ bytes}$**, guaranteeing 100% upload acceptance across both binary and decimal server validators.
