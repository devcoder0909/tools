## How to download a WhatsApp profile picture

A DP is a display picture. If someone shared their profile photo with you as an attachment, save that attachment to your device. Then choose **Profile photo (DP)** and select the file. If you have a direct HTTPS link to the picture, paste it and choose **Load media**. On a computer, you can also copy an image and paste it into the link field.

Choose **View original size** to inspect details, then close the preview and select **Download profile photo**. A PNG downloads as a PNG, and an animated GIF keeps its frames. If all you have is a phone number or a WhatsApp chat link, ask the owner to share the photo as an attachment.

## What happens if I enter a WhatsApp number?

Choose the country and enter the national number, or paste a full international number starting with +. **Open chat in WhatsApp** takes you to that conversation so you can ask for the picture. To create a download here, use the shared image, a direct photo link or a file you already have.

## Is the downloaded WhatsApp DP full size or HD?

Read the pixel dimensions beneath the preview. A 320 × 320 thumbnail downloads at 320 × 320. If you have a 1200 × 1200 original, use that file to keep the extra detail. The small preview fits your screen, while the original-size view lets you scroll across a larger picture. Downloading saves the supplied file without resizing or JPEG recompression. If you paste from the clipboard, the browser saves the image format supplied by the clipboard.

If you need a different crop for your own profile, save the original first. Use the [image cropper](/crop-image/) to frame the subject and leave space around its edges. For a picture with the correct composition but the wrong dimensions, use the [image resizer](/resize-image/).

## Save a status photo or video

Choose Status photo or video to work with an image, an MP4, or a WebM clip. If a contact shared their original status video as a file, select that file and use the player to check the clip before downloading it. The saver copies the original bytes without applying a second round of video compression. To keep the sound and motion, choose the video file itself. A screenshot contains only a still frame.

## Which links work?

If you copied a link from a message, open it and check what appears. A photo or video displayed on its own is a candidate for the Direct media link field. If you see a page with comments, navigation, or a sign-in prompt, ask for the attachment instead. For a file already in your Downloads folder, use the file picker and skip the link field.

A direct media URL returns the picture or video file. A chat link, a Status screen, or an invitation points to a conversation or page instead. The browser also needs permission from the source host to read a remote file. If a link opens in another tab but fails to load here, choose a copy from your device or ask the sender for the original attachment.

The local file stays in the browser. For a link, the browser requests the file from the host you specify. Changing the media selection clears the previous preview. Save before leaving the page if you want to keep the copy. This independent tool does not connect to a WhatsApp account or retrieve someone else's private updates.
