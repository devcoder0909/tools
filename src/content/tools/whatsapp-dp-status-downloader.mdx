## Save a WhatsApp display picture

A DP is the profile photo shown for a contact or account. Choose Profile photo when you have the actual picture, such as an original shared with you by its owner. Paste its direct HTTPS image link and select Load media, or select the image from your device. Check the preview before choosing Download profile photo. The filename identifies the saved copy as a DP and keeps the extension for its media format.

If you need a different crop for your own profile, save the original first. Use the [image cropper](/crop-image/) to frame the subject and leave space around its edges. For a picture with the correct composition but the wrong dimensions, use the [image resizer](/resize-image/).

## Save a status photo or video

Choose Status photo or video to work with an image, an MP4, or a WebM clip. If a contact shared their original status video as a file, select that file and use the player to check the clip before downloading it. The saver copies the original bytes without applying a second round of video compression. To keep the sound and motion, choose the video file itself. A screenshot contains only a still frame.

## Which links work?

A direct media URL returns the picture or video file. A chat link, a Status screen, or an invitation points to a conversation or page instead. The browser also needs permission from the source host to read a remote file. If a link opens in another tab but fails to load here, choose a copy from your device or ask the sender for the original attachment.

The local file stays in the browser. For a link, the browser requests the file from the host you specify. Changing the media selection clears the previous preview. Save before leaving the page if you want to keep the copy. This independent tool does not connect to a WhatsApp account or retrieve someone else's private updates.
