## Scan a screenshot on the same phone

If a QR code arrives in a message, save the image or take a screenshot with all four corners visible. Choose **QR code image** above and select the screenshot from your files or photo library. You can do this on the phone displaying the code without pointing a second camera at the screen.

The scanner reads the image on your device. When it finds a code, the decoded content appears in a text field. Copy the result to use it elsewhere. If the code contains a web address, check the full address and hostname before choosing to open the link. Decoding shows what the code contains, and opening the destination is a separate action.

## What if the code contains text instead of a link?

QR codes can hold a short note, contact details, a Wi-Fi configuration or a web address. A plain-text result is expected for many labels. For a Wi-Fi code, the result may include the network password, so take care when sharing a screenshot of the decoded text. The tool displays the payload without joining the network or adding a contact.

## When a QR code will not scan

Try the original PNG or a clearer photo. Include the blank margin around the square and avoid cutting off any corner. For a screenshot with several codes, use the [image cropper](/crop-image/) to isolate the one you need. Glare, folds and a small code surrounded by a large background can make recognition harder.

To test a printed label, create a sample with the [QR code generator](/qr-code-generator/), scan the exported image and compare the decoded value with the original. If the image contains ordinary printed words, use [Image to Text](/image-to-text/) to extract those instead.
