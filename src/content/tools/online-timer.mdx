## The Computer Science of Drift-Free Browser Timing: Target Epoch vs `setInterval`

Many simple online countdown timers fail when users switch browser tabs or work in another program because they rely on naive interval loop counters (`timeRemaining -= 1` every $1,000\text{ms}$).

### The Background Tab Throttling Problem
To preserve laptop battery life and reduce mobile CPU heat, modern web browsers (Chrome, Safari, Firefox, Edge) aggressively throttle background tabs. Timer callbacks are delayed by up to several seconds or paused entirely during intense garbage collection or system sleep. A naive 10-minute countdown running in a background tab can easily take 14 minutes of real wall-clock time to reach zero.

### ZixTool's Target Epoch Monotonic Anchor
To ensure mathematical precision, ZixTool avoids relative tick counters. Instead, the engine calculates an absolute future **Target Epoch Timestamp** at the exact millisecond the user presses Start:

$$T_{\text{target}} = \text{performance.now()} + (\text{Hours} \times 3600 + \text{Minutes} \times 60 + \text{Seconds}) \times 1000$$

With every display frame refresh, the remaining duration is evaluated against the hardware monotonic clock:

$$\text{Time Remaining} = \max(0, T_{\text{target}} - \text{performance.now()})$$

Because the remaining time is calculated against hardware CPU timestamps, the countdown remains bit-exact even if your computer enters a sleep cycle, your operating system updates its network time (NTP), or the browser tab is hidden in the background for hours.

## Web Audio API Sound Alarms & Browser Autoplay Policies

Modern web browsers enforce strict **User Activation & Autoplay Security Policies** to prevent annoying background tabs from blasting unsolicited sound. Web pages cannot play audio unless the user has explicitly interacted with the page:

- **User Gesture Activation:** Because ZixTool's timer requires the user to click the **Start** button or press the keyboard **Spacebar**, the user interaction unlocks the browser's `AudioContext` permission.
- **Synthesized Melodic Chime:** When the countdown reaches zero, the audio engine uses an `OscillatorNode` with an exponential decay `GainNode` to synthesize a clear, soothing bell chime. Because the sound is generated algorithmically via mathematical sine waves, it plays instantly with zero audio buffering latency.
