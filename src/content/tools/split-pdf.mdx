## Object Tree Pruning and Cross-Reference Table Reconstruction

A Portable Document Format (PDF) file is a directed acyclic graph of indirect objects. Pages are organized in a balanced tree structure rooted at the Document Catalog's `/Pages` node. Each page object references shared resource dictionaries (`/Font`, `/XObject` images, color spaces) and binary content streams.

When you split a heavy PDF into smaller documents or extract a specific range of pages, naive tools simply copy the entire file and delete unselected pages from the tree, leaving megabytes of unreferenced orphan objects, fonts, and images trapped inside the file. 

ZixTool executes a sophisticated **client-side object tree pruning algorithm** using WebAssembly:
1. **Dependency Traversal:** Traverses only the objects reachable from the selected page nodes.
2. **Resource Pruning:** Strips unreferenced fonts, image XObjects, and metadata associated with excluded pages.
3. **Cross-Reference Table Rebuilding:** Generates a clean, compact cross-reference table (`xref`) mapping the new object byte offsets with zero dead weight.
4. **Isolated Document Catalog:** Constructs an independent, ISO 32000 compliant trailer and catalog for each extracted document.
