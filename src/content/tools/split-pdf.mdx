## Flexible Page Range Syntax Guide

ZixTool features an intuitive range parser that gives you complete precision over what pages to extract:

- **Single Pages:** Enter standalone comma-separated page numbers such as `1, 4, 9` to pull individual sheets out of a larger file.
- **Continuous Ranges:** Use a hyphen to define page spans, such as `1-5` or `12-25`.
- **Combined Complex Ranges:** Mix single pages and spans freely, such as `1-3, 7, 10-15, 22`.
- **Extracting Front Matter or Addenda:** Quickly pull just the executive summary (e.g., `1-4`) or the concluding signature addendum (e.g., `45-48`) without needing desktop software.

## Frequently Asked Questions (FAQ)

### Does splitting a PDF reduce document quality?
No. Extracted pages copy the original vector typography, embedded images, and text streams without re-encoding. The extracted pages retain the exact visual fidelity of the original document.

### How do I extract non-consecutive pages (e.g. pages 1, 4, and 7)?
Type a custom comma-separated range into the input box (such as `1, 4, 7-10`). ZixTool bundles those exact pages into a single output file.

### Can I split a PDF to make it small enough for portal uploads?
Yes. When a website rejects an upload because of page count or file size limits, extracting only the necessary pages often brings the document within the required limit. If the extracted document is still too large due to embedded scans, see our [PDF file size limits guide](/guides/pdf-file-size-limits/).

### How does in-browser PDF splitting protect my files?
Because operations run inside your browser's private memory heap using `pdf-lib`, your confidential files are never uploaded to remote servers or stored in third-party cloud queues.
