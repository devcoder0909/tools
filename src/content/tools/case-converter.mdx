## Supported Text Case Formats

Transform text instantly between common literary styles and programming naming conventions:

- **UPPERCASE:** Converts all alphabetic characters to capital letters. Useful for warnings, acronyms, and SQL keywords.
- **lowercase:** Converts all alphabetic characters to standard small letters.
- **Title Case:** Capitalizes the first letter of every word, ideal for blog article headlines, book titles, and essay headings.
- **Sentence case:** Capitalizes only the first letter of each sentence, matching standard conversational prose rules.
- **camelCase:** Removes whitespace and capitalizes the first letter of each subsequent word (e.g., `userAccountBalance`). Standard in JavaScript, TypeScript, and Java variable declarations.
- **kebab-case:** Converts all letters to lowercase joined by hyphens (e.g., `user-account-balance`). Standard in CSS classes, URLs, and Git branch names.
- **snake_case:** Converts all letters to lowercase joined by underscores (e.g., `user_account_balance`). Standard in Python, SQL column names, and database schemas.
