## When to Use Base64 Encoding

Base64 is a binary-to-text encoding scheme that translates raw byte streams into a set of 64 ASCII characters (`A-Z`, `a-z`, `0-9`, `+`, and `/`). Common use cases include:

- **Data URIs in Web Design:** Embedding small PNG or SVG icons directly into HTML or CSS stylesheets to eliminate extra HTTP requests.
- **API Payloads & Headers:** Safely transmitting authentication tokens, cryptographic certificates, or binary attachments within JSON requests without character corruption.
- **Email Transmission (MIME):** Encapsulating binary file attachments in standard SMTP email protocols.
