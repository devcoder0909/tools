## Combine PDF files and check the final page order

Before merging PDF documents, decide the reading order: cover page, main document, then supporting attachments. Use clear source filenames to avoid confusing similarly named downloads. After combining, open the output and inspect the first and last page of each source document.

Merging does not make scanned pages searchable or normalize different page dimensions. A mixture of portrait and landscape pages can remain mixed. Use [Rotate PDF](/rotate-pdf/) to correct orientation and [Split PDF](/split-pdf/) when you need to separate a section again.

Keep the source files until you have checked page count, legibility, and orientation. For electronically signed documents, combining or rewriting the file can affect signature validation; preserve the signed originals. If a portal rejects the result because it is too large, review [Compress PDF](/compress-pdf/) and verify that the reduced copy remains readable.

## Should You Merge First or Compress First?

Users frequently ask: *Should I merge my PDF files before or after compressing them?*

- **Recommended Workflow: Merge First, Then Compress:** In 95% of cases, merging your individual documents first produces a superior, smaller final file size. When documents are unified into a single PDF, document-level font descriptors, duplicate color profiles, and shared object dictionaries are consolidated. After merging, run the unified file through our [Compress PDF Tool](/compress-pdf/) to downsample images and optimize byte streams in one single pass.
- **Exception for Extremely Large Files (100MB+):** If individual files exceed 100 MB each, compressing them individually before merging can prevent browser memory constraints on older mobile devices.

## Troubleshooting Common PDF Merging Inquiries

### How do I handle password-protected PDF files?
If a PDF file is encrypted with an owner or user password, the browser cannot read its internal page tree without decryption. Enter the document password to unlock the file before merging, or print the document to PDF to remove the permission lock.

### What happens if documents have mixed page orientations (Portrait vs Landscape)?
ZixTool preserves individual page rotation attributes. If document A is portrait and document B is landscape, each page retains its native orientation. If you need to standardize page orientation, use our [Rotate PDF Tool](/rotate-pdf/).

### Are interactive form fields (AcroForms) preserved?
Yes. Our engine preserves standard form fields and vector signatures, allowing you to merge filled application forms without losing inputted data.
