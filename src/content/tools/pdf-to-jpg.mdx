## PDF to JPG vs. PDF to JPEG: Is There a Difference?

No. **JPG and JPEG refer to the same image format.** The different file extensions come from historical filename-extension conventions. A `.jpg` file and a `.jpeg` file are both JPEG images; changing the extension alone does not convert the file or change its quality.

ZixTool exports PDF pages as JPG images so they can be opened and used by apps and websites that support JPEG files.

## Comparison: PDF Document vs. JPG Image Format

| Feature / Metric | PDF Document Format | JPG / JPEG Image Format |
| :--- | :--- | :--- |
| **Main purpose** | Preserves document pages, layout, text, and graphics | Stores a visual image as pixels |
| **Text handling** | Text may remain selectable and searchable | Text is part of the image and is not normally selectable |
| **Page structure** | Can contain multiple pages in one file | Usually stores one image per file |
| **Typical uses** | Reports, forms, manuals, contracts, and print-ready documents | Photos, previews, page images, and image uploads |
| **Web embedding** | Commonly displayed with a browser PDF viewer or embedded viewer | Can be displayed with a standard HTML `<img>` element |
| **Editing** | Best edited with a PDF editor | Can be cropped, resized, or adjusted in an image editor |
| **Compression** | Depends on the PDF's text, vector, image, and compression content | Uses lossy JPEG compression, with quality and file size depending on encoding settings |

**Which format should you use?** Keep the original PDF when you need selectable text, searchable content, document structure, or reliable printing. Choose JPG when you need a page as a shareable image or when an upload form specifically asks for JPEG.

## How to Choose the Right JPG Resolution

The resolution you choose affects the pixel dimensions and clarity of the converted page. A higher resolution can make small text and fine details easier to read, but it also creates larger images and may take more memory and processing time.

- **For quick previews and messaging:** Use a moderate resolution when the image will mainly be viewed on a phone or screen.
- **For documents with small text:** Choose a higher resolution so letters, tables, and fine lines remain easier to read when zoomed in.
- **For presentations and larger displays:** Use a resolution that keeps the page legible at the size where it will appear.
- **For upload forms with strict limits:** Start with a suitable resolution, then check the exported JPG's dimensions and file size. Reduce resolution or compress the image if the portal requires a smaller file.

There is no single resolution that is best for every PDF. The original document, page size, content, and intended use all affect the result. JPEG is a lossy format, so repeated re-saving or very aggressive compression can reduce image quality.
