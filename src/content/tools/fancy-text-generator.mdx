## Frequently Asked Questions

### Why does fancy text work on platforms without custom font uploads?
Fancy text uses real Unicode glyphs (Mathematical Alphanumeric Symbols) that modern operating systems and web browsers recognize as universal text characters rather than proprietary font files.

### Does this tool send my text to a server?
No. All character transformation runs instantly in client-side JavaScript within your browser.
