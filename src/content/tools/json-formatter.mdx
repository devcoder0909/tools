## JSON Formatting & Validation Standards

JavaScript Object Notation (JSON), standardized under RFC 8259, is the ubiquitous format for web APIs, application configurations, and database interchange:

- **JSON Beautification:** Indents nested JSON objects and arrays using 2-space or 4-space formatting, making complex API responses legible for debugging.
- **JSON Minification:** Strips extraneous whitespace, indentation tabs, and newline characters to reduce payload size over the wire.
- **Strict Syntax Validation:** Checks for common JSON syntax infractions: trailing commas, single quotes instead of double quotes, unquoted keys, and unescaped control characters.

---

## JSON Specification Rules Table

The table below highlights mandatory RFC 8259 compliance rules:

| Specification Requirement | Valid JSON Syntax | Invalid JSON Syntax |
| :--- | :--- | :--- |
| **String Delimiters** | `"name": "Alice"` | `'name': 'Alice'` (Single quotes invalid) |
| **Key Formatting** | `"status": 200` | `status: 200` (Unquoted keys invalid) |
| **Trailing Commas** | `[1, 2, 3]` | `[1, 2, 3,]` (Trailing comma invalid) |
| **Boolean Values** | `true`, `false` | `True`, `False`, `TRUE` (Must be lowercase) |
| **Null Values** | `null` | `None`, `nil`, `undefined` |
