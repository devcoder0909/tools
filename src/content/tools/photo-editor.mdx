## The Computer Science of Digital Image Processing: Pixel Buffer Math

Under the hood, modern web photo editors operate on raw pixel buffers using an HTML5 `<canvas>` rendering pipeline. When an image is loaded into an `ImageData` array, every individual pixel is represented as four consecutive 8-bit unsigned integers ($0 - 255$) in 32-bit RGBA order:

$$\text{Pixel Byte Offset} = (y \times \text{Width} + x) \times 4$$

### 1. Brightness Adjustment Formula
Brightness adjustments apply an additive linear offset ($\Delta B$) across the red, green, and blue color channels while clamping the output to prevent byte overflow beyond the $0 - 255$ interval:

$$R' = \min(255, \max(0, R + \Delta B))$$
$$G' = \min(255, \max(0, G + \Delta B))$$
$$B' = \min(255, \max(0, B + \Delta B))$$

### 2. Contrast Transformation Formula
Contrast adjusts the distance between light and dark pixels relative to the mid-tone gray anchor ($128$). To adjust contrast by a factor $C \in [-255, 255]$, the contrast multiplier $F$ is calculated:

$$F = \frac{259(C + 255)}{255(259 - C)}$$

$$R' = \min(255, \max(0, F(R - 128) + 128))$$

Increasing contrast pushes light pixels toward pure white ($255$) and shadow pixels toward pure black ($0$), adding dramatic visual punch to flat photos.

### 3. Grayscale Luminance Conversion (ITU-R BT.601 vs BT.709)
Converting a color image into black and white is not a simple arithmetic average ($\frac{R+G+B}{3}$). Because the human eye possesses far more green-sensitive cone photoreceptors than red- or blue-sensitive cones, human vision perceives green light as substantially brighter than blue light.

The standard **ITU-R BT.601** perceptual luminance formula weights color channels according to human photopic vision:

$$\text{Luminance } Y = 0.299R + 0.587G + 0.114B$$

Each pixel's color channels are set to $Y$ ($R' = Y, G' = Y, B' = Y$), producing a natural, balanced black-and-white tonal reproduction.

### 4. Vintage Sepia Tone Matrix Transformation
Sepia simulation reproduces the chemical toning process used in 19th-century silver gelatin prints. The color channels are transformed via a specialized linear matrix:

$$R' = \min(255, (0.393R + 0.769G + 0.189B))$$
$$G' = \min(255, (0.349R + 0.686G + 0.168B))$$
$$B' = \min(255, (0.272R + 0.534G + 0.131B))$$
