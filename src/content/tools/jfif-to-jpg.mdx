### Why Does Windows and Google Chrome Save Images as .JFIF?

If you frequently right-click and save images in Google Chrome or Microsoft Edge only to discover they save with a `.jfif` file extension instead of `.jpg`, your Windows Registry contains an outdated MIME association:

- **The Windows Registry Bug:** A known Windows 10 and 11 glitch causes the registry key `HKEY_CLASSES_ROOT\MIME\Database\Content Type\image/jpeg` to designate `.jfif` as the default extension instead of `.jpg`.
- **Software Rejections:** While `.jfif` is technically a JPEG container, many photo upload portals (government services, job application portals, university forms, Canva, Discord, Photoshop CS6) strictly check file extensions and reject `.jfif` uploads with an *"Unsupported file format"* error.
