## How to Check Your Browser Profile in 3 Steps

Inspect your device and browser diagnostic fingerprint in seconds:

1. **Open Diagnostic Page:** Simply load this page on any computer, tablet, or smartphone.
2. **Review Screen & Client Properties:** Check your screen resolution, color depth, browser language, and active system timezone.
3. **Inspect User Agent:** View your complete HTTP User-Agent string, which web servers use to identify your browser version and operating system.

### Why Network Diagnostics Matter

- **Web Development & QA Testing:** Verify how your browser identifies itself when testing responsive layouts across high-DPI displays.
- **Privacy & Fingerprint Auditing:** Inspect what hardware parameters and device metrics are visible to public websites you visit.
- **Troubleshooting Connection Issues:** Confirm whether cookies, local storage, and proper system timezones are enabled in your browser.

## Frequently Asked Questions

### Is my private browsing information shared with third parties?
No. All diagnostics on Gudmud Convert are read client-side via JavaScript navigator APIs without logging or selling your information.

### What is a User Agent string?
A user agent is a text string your browser includes with every web request so web servers know whether you are using Chrome, Safari, Firefox, Windows, Mac, or mobile.
