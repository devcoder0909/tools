## Understanding Digital Color Formats

Modern web designers and software developers utilize different color models depending on the target rendering environment:

- **HEX (#RRGGBB):** The standard hexadecimal color code used across HTML, CSS stylesheets, and graphic design tools. Each pair represents red, green, and blue intensity from 00 to FF.
- **RGB (rgb(r, g, b)):** An additive color model specifying decimal intensities from 0 to 255 for red, green, and blue. Supports optional alpha transparency as `rgba()`.
- **HSL (hsl(h, s%, l%)):** Represents Hue (0°–360° on the color wheel), Saturation (0%–100% color intensity), and Lightness (0%–100% darkness to brightness). It is widely favored by UI designers for building harmonious color shades and dark mode themes.
