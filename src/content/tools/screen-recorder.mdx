## The Computer Science of Browser Video Capture: MediaStream & MediaRecorder

Historically, recording computer screens required installing heavy third-party desktop software or risky browser extensions with broad system privileges. Modern web standards eliminate external software entirely using standardized browser media pipelines:

### 1. The Screen Capture API (`getDisplayMedia`)
The browser directly queries the operating system's window server (Desktop Window Manager on Windows, Quartz Compositor on macOS, or Wayland/X11 on Linux) using `navigator.mediaDevices.getDisplayMedia()`:

$$\text{OS Compositor} \to \text{Hardware GPU Capture} \to \text{MediaStreamTrack} \to \text{MediaRecorder Engine}$$

This ensures hardware-accelerated frame grabbing directly from the GPU video pipeline, capturing fluid 30fps and 60fps video with minimal CPU overhead.

### 2. Multi-Channel Audio Mixing via Web Audio API
When recording a software tutorial, users frequently need to capture both **system audio** (the audio played by a video, game, or web app) and **microphone narration** simultaneously. 

Because `getDisplayMedia` and `getUserMedia` produce separate audio tracks, ZixTool routes both streams through a browser `AudioContext` and `ChannelMergerNode`. The mixed audio track is bound directly to the master video stream, ensuring that your voiceover and system sound remain in perfect lip-sync synchronization.

### 3. Video Codec Compression: VP9 and Opus in WebM Containers
Recorded video frames and audio samples are compressed on the fly by the browser's native `MediaRecorder` API:
- **Video Codec (VP9 / VP8):** Advanced open video compression standards developed by Google, delivering high visual clarity at substantially reduced bitrates compared to legacy H.264.
- **Audio Codec (Opus):** High-fidelity open audio codec standardized by IETF RFC 6716, dynamically adjusting bitrates from speech ($32\text{ kbps}$) to studio music ($128\text{ kbps}$).
- **Container Format (`video/webm`):** The standard open web media container based on the Matroska (MKV) specification, universally supported across VLC, Chrome, Firefox, Edge, and modern video editors like Premiere Pro and DaVinci Resolve.
