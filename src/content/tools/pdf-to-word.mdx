## Turn selectable PDF text into a Word document

Choose an unlocked PDF and wait for the page counter to finish. The converter creates an editable DOCX with text paragraphs and page breaks. Download the document and open it in Word, LibreOffice or a compatible editor. Compare the text against the original before making changes.

## What transfers to DOCX

This converter transfers the text layer. It does not reconstruct tables as Word tables or preserve images, custom fonts, annotations or the original column layout. Wrapped lines can become separate paragraphs. For an agreement, check subsection numbering and page references. For a table, compare each value with the original row and column before reusing it.

## Handling a scanned PDF

If a page is a photograph of a document, it needs optical character recognition. Save a page image using your PDF viewer, open [Image to Text](/image-to-text/) and review the recognized words before pasting them into your document. A mixed PDF can contain both selectable text and scanned pages. The converter reports pages where it found no selectable text.
