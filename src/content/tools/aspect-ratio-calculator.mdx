## How to Calculate Aspect Ratios for Photos and Videos

Resizing graphics, banners, and video resolutions without distorting or stretching the image requires preserving the proportional aspect ratio:

1. **Enter Original Dimensions:** Type the original width and height in pixels (e.g., 1920 × 1080).
2. **Select or View the Ratio:** The calculator simplifies your dimensions to standard ratios (e.g., 16:9, 4:3, 1:1).
3. **Resize Proportionally:** Enter a new target width to get the exact scaled height, or enter a new target height to get the matching width automatically.

---

## The Aspect Ratio Scaling Formula

Aspect ratio represents the proportional relationship between an image's width and its height. When scaling either dimension while preserving aspect ratio:

```
Scaled Height = (New Width * Original Height) / Original Width
Scaled Width = (New Height * Original Width) / Original Height
```
