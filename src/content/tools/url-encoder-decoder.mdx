## Why Percent-Encoding is Critical for Web Infrastructure

The Uniform Resource Identifier (URI) specification (RFC 3986) designates specific reserved and unreserved character ranges:

- **Reserved Characters:** Characters such as `:`, `/`, `?`, `#`, `[`, `]`, `@`, `!`, `$`, `&`, `'`, `(`, `)`, `*`, `+`, `,`, `;`, and `=` serve syntactic functions within a URI delimiter tree.
- **Unreserved Characters:** Standard alphanumeric characters (`A-Z`, `a-z`, `0-9`), hyphens (`-`), underscores (`_`), periods (`.`), and tildes (`~`) are universally safe and never require escaping.
- **Query Parameter Safety:** When passing search queries containing characters like `&` or `=`, failing to percent-encode them causes HTTP servers to interpret them as separate parameter delimiters, corrupting server payloads.

## Common ASCII Characters and Their Percent-Encoded Representations

| Character | Description | Percent-Encoded Hex Code |
| :--- | :--- | :--- |
| **Space (` `)** | White space separator | `%20` or `+` |
| **Exclamation (`!`)** | Exclamation mark | `%21` |
| **Quotes (`"`)** | Double quote symbol | `%22` |
| **Hash (`#`)** | URI fragment anchor | `%23` |
| **Ampersand (`&`)** | Parameter query delimiter | `%26` |
| **Slash (`/`)** | Path hierarchy separator | `%2F` |
| **Colon (`:`)** | Protocol / port delimiter | `%3A` |
| **Equal (`=`)** | Key-value separator | `%3D` |
| **Question (`?`)** | Query string initiator | `%3F` |

Our URL encoder and decoder runs entirely on client-side ECMAScript routines (`encodeURIComponent` and `decodeURIComponent`). Your private tokens, session identifiers, and API keys are never leaked to external telemetry endpoints.
