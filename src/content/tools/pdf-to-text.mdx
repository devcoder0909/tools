## Extract text from a PDF document

Choose an unlocked PDF with a selectable text layer. The extractor reads pages in document order and joins the text into a plain text file. Select any passage in the preview to copy it, or save the entire document using Download text file. Open the saved file in a text editor to check line endings and reading order.

## Working with scanned pages

A page that looks like printed text can actually be one large picture. If the extractor reports empty pages, export those pages as images with your PDF viewer and use [Image to Text](/image-to-text/) to recognize the words. For a mixed document, compare the page count with the preview before treating the text as complete.

## Checking a plain text export

Check the first and last paragraph on several pages. Page headers and footers can interrupt a sentence. In a two-column paper, a PDF may store lines in a different order from their visual arrangement. Plain text does not preserve columns, charts, clickable buttons or font styles. Keep the original PDF alongside your text copy.
