**Document Version:** 2.0

---

## 1. Executive Summary & Topical Strategy

New websites cannot rank #1 on competitive, high-head search queries like generic "PDF editor", "currency converter", or "scientific calculator" against tenured giants (Adobe, Smallpdf, Google's built-in oneboxes). Attempting to host 80+ thin, disconnected utilities (from media recorders to JoSAA cutoffs and mortgage calculators) dilutes crawl budget, confuses Google's semantic entity clustering, and triggers Quality/Spam score penalties.

**Winning Strategy: Depth & Specific Intent Over Head Breadth**
1. **Target-Size Image Cluster:** Extremely high user intent, strict byte budget requirements (20KB, 50KB, 100KB, 200KB, 500KB, 1MB), thin incumbent competition.
2. **Modern & Awkward Image Pair Converters:** Unresolved consumer pain points (HEIC, AVIF, WebP, JFIF, TIFF to universal JPG/PNG).
3. **Image-to-PDF Utilities:** Clean, client-side, zero-upload document generation.
4. **Deterministic Core Calculators & Text Utilities:** Exactly verifiable mathematical calculations and developer text formatters with zero external API dependencies or financial advice liability.

## 3. Subdomain Migration Plan: JoSAA Cutoffs & College Predictors

### Current Status on `convert.gudmud.site`
- 119 Indian engineering colleges (`/colleges/[slug]/`)
- 119 JoSAA closing rank cutoffs (`/cutoff/[slug]/`)
- Category cutoff indexes (`/cutoff/iits/`, `/cutoff/nits/`, `/cutoff/iiits/`, `/cutoff/gftis/`, `/cutoff/computer-science/`)
- NIRF 2024 ranking indexes & 12 state rankings (`/nirf-ranking/`)
- College rank predictors (`/jee-main-rank-college-predictor/`, `/jee-advanced-rank-college-predictor/`)
- JoSAA counseling guides (`/guides/*`)

### Why This Hurts `convert.gudmud.site`
Hosting 250+ Indian engineering admission pages on a domain named `convert.gudmud.site` confuses search engine crawlers:
- The site's primary entity becomes split between "Global Image & File Converter" and "Indian JoSAA College Admissions".
- Backlink profile and topical relevance are divided, preventing either entity from achieving top-tier search authority.

### Target Subdomain Architecture
- **Target Subdomain:** `cutoffs.gudmud.site` or `colleges.gudmud.site`
- **Clean Separation:** 
  1. Fork the college data layer, UI components, and predictor calculators into a dedicated Astro instance or Cloudflare Pages project.
  2. Implement clean 301 Permanent Redirects on Cloudflare:  
     `https://convert.gudmud.site/colleges/*` $\to$ `https://cutoffs.gudmud.site/colleges/*`  
     `https://convert.gudmud.site/cutoff/*` $\to$ `https://cutoffs.gudmud.site/cutoff/*`  
     `https://convert.gudmud.site/nirf-ranking/*` $\to$ `https://cutoffs.gudmud.site/nirf-ranking/*`  
     `https://convert.gudmud.site/jee-*-predictor/*` $\to$ `https://cutoffs.gudmud.site/jee-*-predictor/*`
  3. Remove college XML sitemap shard from `convert.gudmud.site` and register on Google Search Console under the dedicated subdomain property.
