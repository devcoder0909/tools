## 1. Page Type Specifications

### Type A: Pair Tool Page (`/heic-to-jpg/`)
- **Title Formula:** `{From} to {To} Converter - Free, No Upload | Best Converter` ($\le 60$ chars).
- **Meta Description:** `Convert {From} to {To} free in your browser. Photos never leave your device, no sign-up, no file limits, and you can batch convert and download as ZIP.` (120-158 chars).
- **H1:** `{From} to {To} Converter`.
- **Above The Fold:** Breadcrumbs, H1, unique 1-line promise, working `ToolShell` with drop zone & quality slider.
- **Below The Fold:**
  1. 3-step how-to ordered list (`<ol>`).
  2. Mobile device instructions (iOS Safari & Android Chrome).
  3. "Why Convert" explanation addressing cross-platform software compatibility.
  4. Full comparison table ({From} vs {To}) covering compression, file size, transparency, color depth, browser support, and best uses.
  5. Measured before/after file byte table from our own engine.
  6. 8-12 verified FAQs.
  7. 4-6 curated related tools & format hub link.
  8. Last reviewed date in `<time datetime="...">` and named reviewer team.
